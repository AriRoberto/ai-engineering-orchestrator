# Como contribuir

Crie o trabalho a partir de `develop` usando
`agents/<agente>/<tipo>-<descricao>-<id>`. Execute `python -m ruff check .` e
`python -m pytest`, depois abra um Pull Request em modo rascunho. Escritas diretas em `main`, `master`
e `develop`, force push e merges automáticos são proibidos. Nunca inclua dados de clientes ou
credenciais reais.
